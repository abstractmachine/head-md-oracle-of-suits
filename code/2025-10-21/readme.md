# Goals
Today's class will be focused on learning the core fundamentals of coding, and most importantly, on how to work with classes and objects.

## Quickstart
- Create a folder with today's date
- Create a new P5 sketch via `View` → `Command Palette` → `Create P5.js project`
    - This opens your OS file browser
    - Create a new folder with a cool name
    - Click `Open` with that folder selected
    - This should create a new `P5.js` sketch with all its files inside that folder
    - If the process put files in the wrong place, just delete the files and start the process over
- Open a local Preview window by right-clicking on `index.html` → `Show Preview`
